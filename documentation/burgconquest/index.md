# BurgConquest / CastleConquest 1

BurgConquest or Castle Conquest 1 is a map and gamemode about defending or capturing a castle.

It was originally created only with command blocks and redstone, but later, also datapacks were used. The map still runs in vanilla Minecraft up to version 1.19.

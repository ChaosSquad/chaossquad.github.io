## General

Free mode is a "gamemode" which can be used to explore the map.

## Features
- All castle systems are available, just like in normal gamemodes.
- The castle has [all upgrades](../map/upgrades.md) on max level.
- Every player has an "implanted keycard" which can be used to open/close all doors.
- PVP is disabled by default, but each player can decide if they want to enable pvp for themself.

[:simple-github: CombatTest](https://github.com/ChaosSquad/CombatTest) - source code and issues.

## What is CombatTest?

CombatTest is a Team Deathmatch and Free for all (FFA) Minecraft gamemode on various maps.

It was originally created to test the equipment system of the conquest mode of Castle Conquest 2. Over the time, it developed to its own gamemode.
